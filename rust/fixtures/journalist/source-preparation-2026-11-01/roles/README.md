# Role separation screen

This frozen 12-call screen separates who is discussed from who speaks and requires
the known three topic slots. The Donte speaker error disappears, but outputs
still duplicate or misassign topics and lose qualifications. The manual-reference
gate failed, so no automatic extraction calls were run here.

See the [complete investigation](../README.md), [review](review.json),
[stopping decision](selection.json), [protocol](protocol.txt) and
[measurements](measurements.json). The role-separated extraction prompt and schemas
were subsequently tested with the qualified worked-example writer, not this
failed writer contract.
